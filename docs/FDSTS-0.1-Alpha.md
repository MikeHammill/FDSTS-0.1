# FDSTS 0.1 Alpha

## First milestone

The application foundation establishes:

- WPF Windows application
- Seven-workspace navigation
- Business logic project
- Data project foundation
- Rules project foundation
- Reporting project foundation
- Test project foundation

## Workspaces

1. Home
2. Financial Position
3. Planning
4. Decisions
5. Insights
6. Reports
7. Administration

This release is intentionally a foundation. Financial data entry, SQLite persistence, observations, decisions and reporting will be added incrementally.

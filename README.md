# FDSTS

**Financial Decision Support and Tracking System**

FDSTS is a private Windows desktop application designed to help a household organize financial information, identify items requiring attention, evaluate decisions, and maintain a history of those decisions.

## Version

FDSTS 0.1 Alpha

## Workspaces

- Home
- Financial Position
- Planning
- Decisions
- Insights
- Reports
- Administration

## Technology

- C#
- .NET 8
- WPF
- SQLite (planned)
- Git/GitHub

## Development principle

FDSTS is a decision-support and tracking tool. It does not execute trades, file taxes, or make decisions for the user.
